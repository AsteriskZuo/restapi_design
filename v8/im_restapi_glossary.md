# 介绍

该文档主要面向 restful 开发和使用者， 客户端开发者和使用者。

# 名称

- 权限(authentication)
  - 应用 ID(app_id)
  - 应用 Key(app_key)
  - 令牌(token)
  - 应用级别令牌(app_token)
  - 用户级别令牌(user_token)
- 消息(messages)
  - 消息类型(message_type)
    - 单人消息(private_message)
    - 群组消息(group_message)
    - 聊天室消息(room_message)
  - 消息过程状态(message_process_status)
    - 发送中(sending)
    - 发送失败(send_fail)
    - 发送成功(sended)
    - 接收中(receiving) # 文件类型消息比较慢
    - 接收完成(received)
  - 消息回执状态(message_receipt_status)
    - 已读回执(read_receipt)
    - 送达回执(delivery_receipt)
  - 消息内容分类(message_content_type)
    - 文本(text)
    - 文件(file)
      - 语音(voice)
      - 图片(image)
      - 短视频(short_video)
    - 位置(location)
    - 自定义(custom)
    - 命令(cmd) # 不保存
  - 消息动作(message_actions)
    - 发送(send)
    - 接收(recv)
    - 撤销(cancel)
    - 重试(try)
    - 编辑(edit)
    - 已读/未读(read/unread)
    - 置顶/取消置顶(pin/unpin)
    - 收藏/取消收藏(favorite/unfavorite)
    - 翻译(translate)
    - 回复(reply)
    - 删除(delete)
    - 举报(report)
    - 引用(quote)
    - 转发(forward)
    - 多选(multi_select)
- 会话(conversations)
  - 会话类型(conversation_type)
    - 单人会话(conversation)
    - 群组会话(group_conversation)
    - 聊天室会话(room_conversation)
  - 会话动作(conversation_actions)
    - 置顶/取消置顶(pin/unpin)
    - 免打扰/取消免打扰(mute/unmute)
- 话题(threads)
  - 话题动作(thread_actions)
    - 创建(create)
    - 删除(delete)
- 文件(files)
  - 上传(upload)
  - 下载(download)
- 通知(notifications)
  - 类型(notification_type)
    - 在线通知
    - 离线通知
  - 行为
    - 允许/拒绝(allow/deny)
    - 静默/取消静默(silence/unsilence)
- 用户(联系人、好友)(users)
  - 属性
    - 名称(name)
    - 头像(avatar)
  - 关系
    - 好友(friend)
    - 陌生人(stranger)
- 群组(groups)
  - 属性(group_attributes)
    - 名称(name)
    - 头像(avatar)
    - 备注(remark)
    - 公告(announcement)
  - 类型(group_type)
    - 公开群(public_group)
    - 私有群(private_group)
  - 加入方式(group_join_type)
    - 申请加入(apply)
      - 不需要审批(no_approval)
      - 需要审批(approval)
    - 邀请加入(invite)
      - 不需要审核(no_approval)
      - 需要审核(approval)
  - 成员(group_members)
    - 属性(member_attributes)
      - 名称(name)
      - 备注(remark)
      - 头像(avatar)
    - 行为(group_member_actions)
      - 禁言/取消禁言(mute/unmute)
      - 更改权限(permission) # 设置为管理员、取消管理员等
    - 权限(group_member_permissions)
      - 创建者(creator)
      - 管理员(manager)
      - 普通成员(member)
  - 行为(group_actions)
    - 创建(create)
    - 解散(dismiss)
    - 退出(quit)
    - 加入(join)
    - 邀请(invite)
    - 踢出(kick)
- 聊天室(rooms)
  - 属性(room_attributes)
    - 名称(name)
    - 头像(avatar)
    - 备注(remark)
    - 公告(announcement)
  - 成员(room_members)
    - 属性(member_attributes)
      - 名称(name)
      - 备注(remark)
      - 头像(avatar)
    - 行为(member_actions)
      - 禁言/取消禁言(mute/unmute)
    - 权限(member_permissions)
      - 创建者(creator)
      - 普通成员(member)
  - 行为(room_actions)
    - 创建(create)
    - 解散(dismiss)
    - 退出(quit)
    - 加入(join)
    - 踢出(kick)
- 推送(push)
  - 推送内容属性
    - 标题(title)
    - 昵称(nickname)
    - 内容(content)
    - 首选语言(first_language)
  - 推送绑定属性
    - 设备 ID(device_id)
    - 设备 Token(device_token)
    - 厂商证书(third_certificate)
- 控制台(console)
- 黑名单(blocks)
  - 行为(block_actions)
    - 加入(add)
    - 移除(remove)
- 在线状态(presence)
-

# 通用

- 增加(add) # 添加好友
- 创建(create) # 创建用户
- 删除(delete) # 删除用户
- 移除(remove) # 移除好友
- 修改(更新)(update)
- 查询(query)
- 分页(page)
- 过滤(filter)
- 排序(sort)
- 游标(cursor)
- 分组(group)
- 限制(limit)
- 包含(include) # 是否是好友、是否是群组成员、是否在黑名单等
