# REST API 最佳实践和示例

## 完整API设计示例

以一个博客系统为例，展示完整的REST API设计：

### 资源设计

```
用户管理:
GET    /api/v1/users                    # 获取用户列表
POST   /api/v1/users                    # 创建新用户
GET    /api/v1/users/{id}               # 获取特定用户
PUT    /api/v1/users/{id}               # 更新用户信息
PATCH  /api/v1/users/{id}               # 部分更新用户
DELETE /api/v1/users/{id}               # 删除用户

文章管理:
GET    /api/v1/posts                    # 获取文章列表
POST   /api/v1/posts                    # 创建新文章
GET    /api/v1/posts/{id}               # 获取特定文章
PUT    /api/v1/posts/{id}               # 更新文章
PATCH  /api/v1/posts/{id}               # 部分更新文章
DELETE /api/v1/posts/{id}               # 删除文章

用户文章关联:
GET    /api/v1/users/{id}/posts         # 获取用户的文章
POST   /api/v1/users/{id}/posts         # 用户创建文章

评论管理:
GET    /api/v1/posts/{id}/comments      # 获取文章评论
POST   /api/v1/posts/{id}/comments      # 添加评论
GET    /api/v1/comments/{id}            # 获取特定评论
PUT    /api/v1/comments/{id}            # 更新评论
DELETE /api/v1/comments/{id}            # 删除评论
```

## 性能优化最佳实践

### 1. 字段选择 (Field Selection)

```http
# 只获取需要的字段
GET /api/v1/users?fields=id,username,avatar

# 排除不需要的字段
GET /api/v1/posts?exclude=content,rawContent
```

### 2. 关联数据加载

```http
# 包含关联数据
GET /api/v1/posts?include=author,category,tags

# 嵌套包含
GET /api/v1/posts?include=author.profile,comments.author
```

### 3. 缓存策略

```http
# 响应头
Cache-Control: public, max-age=3600
ETag: "post-1-v3"
Last-Modified: Tue, 01 Jan 2024 12:00:00 GMT

# 条件请求
If-None-Match: "post-1-v3"
If-Modified-Since: Tue, 01 Jan 2024 12:00:00 GMT
```

### 4. 压缩

```http
# 请求头
Accept-Encoding: gzip, deflate, br

# 响应头
Content-Encoding: gzip
```

### 5. 分页优化

```http
# 游标分页 (适合大数据集)
GET /api/v1/posts?cursor=eyJpZCI6MTIzLCJjcmVhdGVkQXQiOiIyMDI0LTAxLTAxVDEyOjAwOjAwWiJ9&limit=20

# 偏移分页 (适合小数据集)
GET /api/v1/posts?offset=40&limit=20
```

```http

Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

X-API-Key: your-api-key

# OAuth 2.0
Authorization: Bearer oauth2-access-token
```

## 文档和测试

### 1. OpenAPI 规范

```yaml
openapi: 3.0.0
info:
  title: Blog API
  version: 1.0.0
paths:
  /users:
    get:
      summary: 获取用户列表
      parameters:
        - name: page
          in: query
          schema:
            type: integer
            default: 1
      responses:
        200:
          description: 成功
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/UserList'
```

### 2. 自动化测试

```javascript
// API 测试示例
describe('用户API', () => {
  test('创建用户成功', async () => {
    const response = await request(app)
      .post('/api/v1/users')
      .send({

    expect(response.body.data.username).toBe('testuser');

```
